# frontend

web user interface.

## structure

- `flaskr/`  
  flask application package  
  templates, static assets, blueprints, component wiring

- `instance/`  
  flask instance folder placeholder  
  can hold per deployment configuration files

## responsibilities

- render search and history pages  
- call backend api endpoints for search, history, stats and config  
- manage client side state and interactions  
- display entities, relationships and sources  
- provide export and dark mode features
