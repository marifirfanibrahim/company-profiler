# frontend / flaskr / templates

jinja2 templates for pages.

## files

- `index.html`  
  main search page  
  sidebar and topbar layout  
  model and perspective selectors  
  search input and recent searches dropdown  
  results section with summary, entities, relationships and export buttons  
  modals for custom perspectives and custom models

- `history.html`  
  search history page  
  filters for query, perspective, sort and page size  
  history item list with compact and detailed view  
  top entities and top relationships section  
  detail modal with summary, entities, relationships and export buttons
