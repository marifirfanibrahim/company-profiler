# frontend / flaskr / static / css

stylesheets for layout, pages and themes.

## files

- `core.css`  
  base layout and typography  
  sidebar, topbar, buttons, forms, modals  
  entity tags, badges, notifications

- `pages.css`  
  page specific styles  
  search area, results, history lists  
  relationships graph container  
  custom perspectives and models modals

- `dark-mode.css`  
  dark theme overrides for all major components  
  adjusts backgrounds, text colors and badges

- `style.css`  
  main entry stylesheet  
  imports `core.css`, `pages.css`, and `dark-mode.css`
