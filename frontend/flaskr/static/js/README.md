# frontend / flaskr / static / js

client side logic.

## files

- `utils.js`  
  shared utilities  
  dark mode toggle and persistence  
  notifications  
  sources rendering  
  export helpers for text, doc and pdf

- `search.js`  
  main search workflow  
  recent searches sidebar  
  request abort handling  
  result rendering

- `config.js`  
  manage custom models  
  fetch model list  
  save and delete models

- `ui_config.js`  
  ui constants  
  sources collapse limits  
  export pdf styling
